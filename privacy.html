Bhaaag privacy

Bhaaag is a free browser game. You can play it without giving us anything. This page says what is stored if you choose to post a time to the leaderboard.

What is stored on this device

Your best times and settings, and, if you post a time, a random player id, a secret key and the name you typed (browser local storage, keys starting with bhagdori.). The secret key proves the id is yours.

What is stored on our server

Only if you post a time or use an invite link: your player id, a one-way hash of the secret key (never the key), the display name you typed, your finish times, an invite code, and who you are friends with. There is no email, login, password, location or advertising id. The server is a Supabase project hosted in Sydney, Australia.

Who can see it

Your display name and best Classic time are public on the leaderboard. Your friends list is visible only to you; friends boards show names and times only. Do not use your real name if you do not want it shown.

Deleting your data

After posting a time, open the win screen and choose Delete my data under the leaderboard. That removes your player, times and friend links from the server and forgets the id on this device. If you no longer have the device, you cannot prove the id is yours; contact the game owner through the GitHub repository (rubenkaksh/bhaaag) with your display name and we will remove it.

Age and changes

The game is for ages 13 and over. We will update this page if what is stored changes.
