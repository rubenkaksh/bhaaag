# Unreal Engine

- Export source textures and documented frame regions.
- Configure texture compression, sRGB, alpha, mipmaps, filtering and virtual-texture settings as appropriate.
- Use Paper2D sprites/flipbooks or material-driven effects where the project supports them.
- Verify pivots, collision geometry, material blend mode and texture sampling.
- Do not imply that an image atlas alone creates a working Niagara effect.
