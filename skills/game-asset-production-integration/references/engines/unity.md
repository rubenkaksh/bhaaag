# Unity

- Export PNG atlases and Unity-compatible metadata, or individual sprites.
- Configure Texture Type as Sprite (2D and UI), alpha transparency, filter mode, compression, pixels-per-unit and platform overrides.
- Use Sprite Editor slicing or generated metadata where supported.
- Configure Sprite Atlas packing, padding and tight packing only when safe.
- Create or update Animation Clips, Animator Controllers, prefabs or Particle Systems as appropriate.
- Verify sorting layers, sorting order, pivots and material/shader behavior.
- Avoid editing serialized Unity YAML blindly; use editor tooling or validated formats.
